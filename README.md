# belemde for Windows

IDE для олимпиадного программирования на C++ и Python.

В выпусках доступны установщик Windows x64 и portable ZIP. Начиная с 0.35.0 приложение проверяет обновления через этот репозиторий.

[Скачать последнюю сборку](https://github.com/Boodoochai/belemde-releases/releases/latest)
